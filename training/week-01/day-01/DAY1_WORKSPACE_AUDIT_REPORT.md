## Safe Workspace Filtering Recommendation
1. **Keep the existing `.gitignore`** – it already blocks `.dart_tool/`, `build/`, and typical dependency caches.
2. **Add patterns for future generated Dart files** (if you adopt code‑gen packages):
   ```gitignore
   **/*.g.dart
   **/*.freezed.dart
   **/*.mock.dart
   ```
3. **Optionally enable Antigravity Strict Mode** (Settings → Strict Mode = ON) to deny any file not explicitly allowed.
4. **Do NOT rely on `.aiignore` or `.cursorignore`** – these are not parsed by Antigravity.
5. **Leave `pubspec.lock` indexed** unless you need a leaner context; it is safe to exclude but be aware of the loss of exact version pins.
6. **No further changes** to the repository are required.

Following these steps ensures the AI workspace focuses on hand‑written source, tests, and essential configuration while safely omitting large, transient, or generated artefacts.
